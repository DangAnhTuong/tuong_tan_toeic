# 🎧 Tường Tận TOEIC - Nền Tảng Luyện Thi TOEIC Hàng Đầu

Dự án Web App Luyện thi TOEIC Toàn Diện với công nghệ **React 19**, **Vite**, **TailwindCSS**, **Node.js Express** và **MongoDB**.

## 🌟 Tất Cả Các Mô-đun Đã Lập Trình Hoàn Chỉnh:
1. 🏠 **Trang Chủ & Hub (`/`, `/hub`):** Đặt mục tiêu điểm số, Chuỗi ngày Streak, XP, Hồ sơ cá nhân.
2. 🎧 **Mô-đun Nghe (`/listen`):** Luyện nghe 4 Parts, Nghe chép chính tả 3 chế độ với audio player dạng sóng âm.
3. 📖 **Mô-đun Đọc & Ngữ Pháp (`/read`):** Part 5, 6, 7 + Lý thuyết ngữ pháp chi tiết + Đọc song ngữ Anh–Việt.
4. ✍️ **Mô-đun Viết (`/write`):** Part 1 Viết câu theo tranh + Part 2 Viết Email phản hồi (Đếm ngược 20 phút).
5. 📚 **Mô-đun Từ Vựng SM-2 (`/vocabulary`):** Thuật toán lặp lại ngắt quãng Spaced Repetition (4 nút 🔴 Again, 🟠 Hard, 🔵 Good, 🟢 Easy) + Đồ thị Đường Quên Ebbinghaus.
6. 📝 **Mô-đun Đề Thi TOEIC Thực Tế (`/tests`):** Bộ đề 200 câu 7 Parts từ 2019-2026 + Phòng thi thử 100vh No-scroll.
7. 📺 **Mô-đun Video Học Bài (`/video`):** Bài giảng video Vietsub + Bài tập thực hành bên dưới + Accordion 9 Chương.
8. 🏆 **Mô-đun Bảng Xếp Hạng (`/leaderboard`):** Hall of Fame Top 3 Podium + Live Feed hoạt động.
9. 💬 **Menu Rút Gọn (`... More`):** Blog, Về Tường Tận TOEIC, Cộng đồng, Liên hệ, Đề xuất, Feedback.

## 🚀 Hướng Dẫn Khởi Chạy:
- **Backend Node.js**: `cd backend && node src/server.js` (Cổng 5000).
- **Frontend React Vite**: `cd frontend && npm run dev` (Cổng 3000).
